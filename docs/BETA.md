# 内测反馈流程

建议邀请 5–10 位真实沪漂用户，覆盖 Android/iPhone、不同屏幕和网络。项目负责人自行邀请；系统不会假造真人或自动生成测试建议。目前没有真实测试者反馈，不能宣称完成内测。

第一轮测试进入社区、草稿、待审核提示、审核后展示、回复及分页。第二轮测试断网恢复、重启、深链、重复点赞、屏蔽/取消屏蔽、举报和删除匿名身份。第三轮让测试者自然使用，评价分类、可读性和匿名安全感。

用户在“内测反馈”提交问题、建议或安全问题，写明复现步骤、期望和实际结果。仅随主动提交记录系统/版本及应用版本；不要附登录令牌、密码或个人敏感信息。管理员在 `/admin` 更新状态和回复，只有提交者能看到自己的反馈。

每轮保存构建版本、设备、日期、用例结果和未解决问题。严重问题停止发放构建，修复后复测；按影响和复现频率排序建议。

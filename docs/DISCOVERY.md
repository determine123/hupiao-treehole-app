# 1.0.1：沪漂广场与社区指南

参考 https://litebbs.com/ 的广场、最新、热门和使用手册信息组织，保留沪漂树洞原有匿名身份与原创界面，没有复制其帖子、用户数据或品牌素材。

- 广场新增最新、本周热门、等待回应，兼容版块、关键词和个人互动筛选。
- 热门只计算过去七天内容，按共鸣 + 公开回复 × 2、发布时间、ID 排序；最多 50 条，无无限分页。榜单实时变化，下拉刷新重新计算。
- 等待回应按公开回复为零筛选；待审核回复不会计入。沿用时间/ID 游标分页。
- 所有列表继续检查审核状态和屏蔽关系，不显示其他人的待审核或隐藏内容。
- 新增社区公告、新手指南、搜索按钮、清除搜索与网络重试；切换筛选时清除旧列表，避免误以为旧结果属于新筛选。
- 本版仍先审后发，不承诺审核时限；不展示虚构签到榜、人气或用户。

新版需要安装 1.0.1 APK。保持包名与 EAS 签名，可覆盖安装；不要先卸载，否则匿名身份可能丢失。原网站没有切换。
